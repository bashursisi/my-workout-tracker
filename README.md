# Workout Tracker

A simple workout log: 6-day rotation, date picker, progression hints and history.
Data is stored in the browser on each device (localStorage). Nothing is sent to a server.

## Put it on GitHub Pages
1. Create a new repository on github.com (e.g. `workout-tracker`), public or private.
2. Upload all files in this folder (index.html, manifest.webmanifest, sw.js, README.md and the icons folder).
3. Go to Settings > Pages, choose "Deploy from a branch", branch `main`, folder `/ (root)`, and save.
4. After about a minute, the app is at https://<your-username>.github.io/workout-tracker/

## Install on iPhone
1. Open the GitHub Pages link in Safari (must be Safari, not Chrome).
2. Tap the Share button, then "Add to Home Screen", then "Add".
3. Open "Workout" from your home screen. It runs full screen like an app and works offline after the first load.

Note: data is per device and per browser. Entries on your iPhone won't appear on your computer.
